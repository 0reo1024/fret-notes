# Fret Notes Desktop

Work版のFret Notesを、Tauri 2 + TypeScript + RustでWindowsデスクトップソフトへ段階的に移行しています。現在は第4段階（単音の演奏練習）の実装版1.1.0です（即興トレーニング拡張の P0〜P15 と、演奏練習の苦手ランキングを含む。[拡張計画](docs/training-expansion/README.md)）。実機接続の再確認は後日に残しています。

## 起動

`Start Fret Notes.cmd` をダブルクリックしてください。ビルド済みの場合は `release/Fret Notes.exe` を起動します。exeを直接開くこともできます。通常の利用にはNode.jsや開発サーバーは不要です。Microsoft Edge WebView2 Runtimeを使用します。

設定はWindowsのアプリデータ領域 `jp.fretnotes.desktop` の `settings.json` に保存します。直前の正常な設定もバックアップします。ブラウザーの旧設定は自動移行されません。

画面は左の機能切り替え、中央の指板・練習画面、右のプロパティで構成しています。コード・スケールの表示条件や演奏練習の判定条件は右側で変更します。中央と右側は個別にスクロールでき、音声入力の開始・停止は右パネルの上部に固定しています。小さい画面では「表示・出題設定」でプロパティを開閉でき、Escでも閉じられます。

## 現在使える機能

- ギター・4弦/5弦ベースと楽器別設定
- 標準、Drop D（ギター・4弦ベース）、Drop A（5弦ベース）、半音下げ
- 開放音とオクターブを指定する独自チューニング（楽器ごとに12件）、編集・削除
- 位置→音名（自己確認／選択肢／音名入力）、音名→位置、全位置探索、全音名表示。反応時間の平均・中央値
- 19種類のコード、21種類のスケール、最大4層の比較と度数確認
- 標準チューニングのコードシェイプ、出題範囲設定、キーボード操作
- PCへの設定自動保存、JSON書き出し/読み込み
- 入力デバイス・チャンネルの選択、音声入力の開始/停止
- クロマチックチューナーと開放弦の目標音、周波数・音名・セント差・入力レベル
- A4基準（400〜480 Hz）と無音しきい値、無音/不安定/入力過大時の表示解除
- 単音の演奏練習（オクターブ指定／自由）、位置を表示しない指板、安定判定、正解後の自動送り、一時停止/再開、今回の結果
- ハーモニー：コードトーン瞬間回答、インターバル（音名・指板の形）、アルペジオ（転回形・弦セット）、調と機能（ディグリー・T/SD/D・セカンダリードミナント）
- 進行（コードチェンジ）：コード進行に合わせてルート・3rd・7th・3rd と 7th・コードトーン・9th を弾く（ステップ式）。進行ライブラリと自作の進行
- 耳・リズム（リズム）：パターンをタップまたはギター（試験的）で打ち、各打点のずれ（ms）、走る・もたる傾向、ばらつきを表示。遅延の補正
- 耳・リズム（聴音）：アプリが鳴らす短いフレーズをギターで再現する（歌ってから弾くことも可）。難しさの自動調整
- 指板学習のスケール表示で、ルート＋5度のドローンを鳴らせる
- 学習記録（「記録」タブ）：今日の練習（自動のメニュー）、今日・直近7日の問題数・正答率・回答時間、連続練習日数、記録した項目・定着・復習の数、レベル L1〜L7 の進み具合、弱点の交差表と「苦手を練習」、入力の状態、目標の反応時間。書き出し/読み込み/消去

チューニングは右側のプロパティ（小さい画面では「表示・出題設定」）から変更できます。指板・出題・回答判定に一括反映し、出題を最初から開始します。独自設定は標準プリセットを変更せず、名前を付けて保存できます。

シェイプは開放弦の絶対音高が標準と一致する場合に表示します。異なる場合は未対応の案内を出します。コード/スケールの構成音はどのチューニングでも表示できます。任意チューニング用の運指生成は後続段階です。

保存形式はschemaVersion=3です。schemaVersion=1/2を自動移行し、楽器別の練習・チューニング設定を保持して音声設定を追加します。旧ファイルは `settings.v1.backup.json` / `settings.v2.backup.json` に保管し、通常のバックアップ更新後も残します。

## チューナー

左側の「チューナー」から開き、入力デバイスとチャンネルを選んで「入力を開始」を押してください。入力は自動開始しません。楽器は上部から切り替え、チューニングは指板学習の設定欄で変更します。弦を選ぶと、その開放音をオクターブ込みの目標にします。クロマチック表示では最も近い音を表示します。

単音を弾き、他の弦をミュートしてください。対応音域は25〜1500 Hzです。目標が音域外の場合、その弦の目標選択を無効にします。音高が安定したときだけ音名を表示し、目標の±5セント以内を緑で示します。無音、不安定、入力過大、データの途切れでは成功表示を保持しません。

このPCの実音検証では **Nano Cortex (3+4) / 入力1** からギター6弦開放EをE2として検出しました。Nano Cortex (1+2)は検証時に約−97 dBのほぼ無音でした。全機器・全音域の実音精度を保証するものではなく、低いベース音と実際の抜き差し・スリープの確認は継続課題です。

「停止」、指板学習への切り替え、最小化、終了で入力を閉じます。入力エラー、1秒以上のデータ途切れ、2秒以上の画面への通知中断でも停止します。再接続後は「入力一覧を更新」から選び直して開始してください。音声ファイルは保存しません。

## 演奏練習

「指板学習」で弦・フレット・ナチュラル音の範囲とチューニングを設定し、「演奏練習」へ切り替えてください。音域内の位置から5/10/20問を出題します。許容幅は±5/10/20セント、安定時間は200/350/500 msから選べます。入力を選び「練習を開始」を押すと判定を始めます。一時停止後は「練習を再開」で続けます。

「6弦の E を演奏」の形式で出題します。押さえるフレットは表示しません。音の高さとオクターブを判定し、同じ高さの音は別の弦で弾いても正解になります。正解すると中央に緑の「正解！」を600 ms表示して、自動で次の問題へ進みます。ミュートは待ちません。正解表示中は重複加点せず、次の問題では改めて安定した音を確認します。

一時停止、画面切り替え、入力中断では同じ問題と結果を保持し、再開時には安定判定を最初から行います。楽器・チューニング・出題範囲・基準周波数を変更すると練習を作り直します。判定条件は開始前に選び、変更するには現在の練習を終了してください。全問正解または「練習を終了」で入力を停止し、正解数、許容範囲外の安定した音の回数、正解した問題の聴き取り時間を表示します。

### 苦手ランキングと苦手集中

指板の下に、その日の苦手な位置（出題した弦・フレット）を苦手な順に表示します。音声では弦を判定できないため、「5弦 3F」は出題した位置で、実際に押さえた弦ではありません。

- 苦手度（点）: 間違えた割合（間違えた回数 ÷ 出題数）と平均解答時間を半分ずつ使います。2問に1回間違え、目標の反応時間（記録タブ。演奏の既定は4秒）ちょうどかかる位置が100です。出題が少ない位置は「ふつう」の値に寄せて計算するので、1問だけ遅かった位置が上位を占めにくくなっています。70以上を「苦手」と表示し、出題が3問未満の行には「参考」と付けます。
- 間違えた回数: 目標と違う音を安定時間以上鳴らした回数です。答えずに終えた問題（「練習を終了」、設定・楽器の変更）は、間違えたか目標時間を超えていた場合だけ、間違い1回と時間の上限（目標の3倍）を加えて記録します。1問の時間も目標の3倍で打ち切ります。
- 日ごと: ランキングは端末の日付ごとの記録で作り、練習のたびに更新します。「‹」「›」と日付の一覧で前の日を表示できます。「前回比」は前の記録日の順位との差です。目標時間を変えると、過去の日の苦手度も新しい目標で計算し直します。
- 表示中の楽器・チューニングの記録だけを使います。出題範囲では絞りません。オクターブ「自由」の結果は弦を指定しないため集計しません。

右側の「苦手集中」（入力設定の上）をオンにすると、苦手度40以上の位置を上から最大5／10／15か所だけ出題します。出題範囲の設定は使わず、操作できなくなります（値は変わりません）。元にするのは今日の記録です。今日の候補が2か所に満たないときは、候補が2か所以上ある最新の日を使います。どの日にも足りなければ通常の範囲で出題します。選んだ位置は練習を作った時点で固定し、練習中には入れ替えません。オクターブ「自由」では使えません。

正解した問題は学習記録として保存します（下記）。判定条件と今回の結果の表示は画面内だけで保持します。今回の版では履歴DB・メトロノーム・リズム採点を追加していません。実際に弾いて一連の練習を完了する確認は、Nano Cortex再接続後に行います。

## 指板学習の回答方法と全位置探索

「位置 → 音名」は、右側のプロパティの「回答方法」で自己確認（従来どおり）・選択肢・音名入力を選べます。選択肢はキー 1〜4、音名入力は A〜G で音名、↑↓ で ♯・♭、Enter で回答します。♯・♭ どちらの綴りでも正解です（E♯ や二重変化記号など、同じ高さの別の綴りは「正解（綴りに注意）」）。Space は答えを見る（スキップ）です。

「全位置探索」は「範囲内のすべての C を選択」の形で出題します。該当する位置をすべて選び（もう一度選ぶと解除）、Space で採点します。緑が正解、橙が誤り、点線が見落としです。音名ごとに一巡するまで重複しません。

選択肢・音名入力・音名→位置・全位置探索の結果と反応時間を学習記録に残し、今回の平均・中央値を画面下部に表示します。演奏練習の「オクターブ: 自由」では、練習範囲内のどの高さで弾いても正解になります（例: E2 の問題で E3・E4 も正解）。

## ハーモニー（コードトーン瞬間回答）

左の「ハーモニー」で、「G7 → 3rd と 7th ?」のようにコード名と問う音を表示します。問う音は 3rd と 7th（既定）・3rd・7th・構成音すべて・9th、コードはトライアド／段階1（maj7・m7・7）／段階2（＋m7♭5・dim7・m(maj7)）／段階3（＋6・m6・9・maj9・m9）、ルートは標準12種類（F♯/G♭を選択）または拡張17種類です。構成式にない音は出題しません（sus に 3rd、6・トライアドに 7th はなし）。dim7 の 7th は減7度（C dim7 なら B♭♭）です。

回答方法は選択肢（1〜4）・音名入力（A〜G、↑↓、Enter）・指板（クリック）・演奏です。「3rd と 7th」は、選択肢と音名入力では 3rd→7th の順に、指板と演奏ではどちらの順でも答えます。正誤は音の高さで判定し、同じ高さの別の綴りは「綴りに注意」として区別します（「綴りも厳密に判定」で不正解にできます）。誤答は「コードの種類の取り違え」「別の構成音」などに分類します。演奏では、選んだ指板の範囲の最低音〜最高音を音域とし、どのオクターブでも正解です（弦は判定しません）。聞こえた音はルートからの度数で示します。マイクが誤認識し続けるときは「スキップ」「正解として扱う」を使えます。入力過大が続いた問題のスキップは入力の問題として記録し、苦手の判定に含めません。

正解すると 600 ms 後に自動で次へ進みます。誤答・時間切れでは正解と指板上の全位置（度数つき）を表示し、Space で次へ進みます。10問・20問・60秒から選び、結果に正答数、反応時間の平均・中央値、誤答の分類、間違えた問題を表示します。すべての回答を学習記録に残します。

## ハーモニーの出題の種類

上部で「コードトーン」「インターバル」「アルペジオ」「調と機能」を切り替えます。設定と回答方法は種類ごとに保存します。

- インターバル：「E♭ から 長3度上 ?」。段階1（短3度・長3度・完全5度・短7度・長7度）〜段階4（9度・11度・13度）、上行・下行。綴りはルートから文字を数えて決めます（B♭ から短3度は D♭、A4 と d5 は別）。標準ルートでは二重変化記号と、増減音程で E♯・B♯・C♭・F♭ になる問題を出しません。「指板の形」を選ぶと、表示したルートの位置から同じ弦・隣の弦・±4フレットの条件で、正確な高さの位置を探します（演奏ではオクターブも判定）。正解後に「1本高い弦の同じフレット」のような位置関係を表示します。
- アルペジオ：「Am ／ 第1転回形 ／ 3-2-1弦 ／ 上行 ／ 5〜8F」。1弦に1音、5フレットの幅に収まる形を、指定の順に指板で選ぶか弾きます（演奏は高さの並びで判定し、弦は判定しません）。間違えたら最初から（または、その音から）やり直し、途中で間違えた問題は不正解として記録します。この形で届かないコード（ギターの dim7 など）は出題しません。
- 調と機能：「E♭ メジャー ／ ii7 は?」「G7 ／ C メジャーでの機能は?」「D メジャー ／ V7/V は?」を選択肢で答えます。マイナーはナチュラルとハーモニックを分け、マイナー II–V–I の V はハーモニックマイナーの V7 です。

## 進行（コードチェンジ）

左の「進行」で、コード進行に合わせて狙う音を弾きます。方式は、正解すると次のコードへ進む「ステップ式」と、メトロノームに合わせてコードが変わる「自動進行」から選びます。

- 進行: ライブラリ（II–V–I メジャー／マイナー、I–IV–V–I、I–vi–ii–V、iii–vi–ii–V–I、ナチュラルマイナーの i–iv–v–i・i–♭VI–♭VII–i、セカンダリードミナント2種、12小節ブルース、ジャズブルースの一例）を好きな調で、または自分で入力した進行で練習します。曲のメロディや歌詞は含みません。
- 段階: 1 ルート、2 3rd、3 7th、4 3rd と 7th（順不同）、5 コードトーンのどれか、6 コードトーン＋9th。3rd のない sus は 4th（または 2nd）、7th のない 6・トライアドは 3rd に置き換え、画面にその旨を表示します。9th は既定では構成式にあるものだけで、「調から 9th を導く」をオンにすると、調のある進行のダイアトニックコードに調の音階の 9th を加えます（マイナーの V7・iiø7 は ♭9）。
- 回答: 演奏（どのオクターブでも可、範囲の最低音〜最高音）または指板のクリック。前のコードから伸ばしている音が次のコードでも狙う音なら、弾き直さなくても正解です（共通音の保持）。間違えた音は数えますが、先へは進めます。
- 画面: 進行表で現在のコードと結果（正解・誤りのあと正解・スキップ）を色で示し、大きく「Dm7 → 3rd（F）」、小さく次のコードを表示します。答えの音名と指板のガイド（表示しない／正解後／常に）は切り替えられます。Space 開始・一時停止、← → 戻る・進む、S スキップ。
- 自動進行: テンポ 40〜160 BPM、コードの長さ（進行どおり／2倍）、クリック（すべての拍／2・4拍／1拍目だけ／なし）と音量。最初に1小節カウントします。各コードの窓はコードの始まりから終わりまでで、検出の遅れを補うため終わりから0.3秒の猶予があります。窓の中で狙う音に届けば「到達」、別の音だけなら「別の音」、何も弾かなければ「届かず」です。各コードに2拍以上・1秒以上ない設定では開始できません。音はアプリ内の合成音で、外部の音声ファイルは使いません。マイクで入力する場合はヘッドホンを使ってください。
- 段階7「自由」（自動進行のみ）: 自由に弾き、採点はしません。コードが変わった直後の最初の音（または伸ばしている音）の度数を進行表の各コードの下に表示し、結果に 3rd/7th への着地の割合を参考として示します。
- ライン（ボイスリーディング、ステップ式）: 各コードで1音ずつ弾き、前の音から近い距離でつなぎます。最初の音（自由／3rd から／7th から）、許可する度数（3rd と 7th／コードトーン）、移動の上限（2半音／4半音）を選びます。条件を満たす経路はすべて正解で、外れた音には「Dm7 の上でこの音は使えません（R）」「前の音から6半音です（上限2半音）」のようにどの条件かを示します。開始前に、条件を満たす経路があるかを確かめます。終わると、あなたのライン（例：F(♭3) → F(♭7) → E(3)）の特徴（共通音の保持、半音・全音、3rd↔7th の入れ替わり、上行・下行）と、同じ最初の音から成り立つ他のラインの例を示します。良し悪しの評価はしません。ヒントをオンにすると、次に使える位置を指板に表示します。
- 自作の進行: 「進行を作る・編集する」で `Dm7 G7 | Cmaj7 |` の形式で入力します（小節は |、1小節に4つまで、別表記の -7・ø・Δ7・b・# も可）。読めないコードはどの小節の何番目かを表示します。保存・複製・削除（確認つき）ができ、学習記録と同じファイルに100件まで保存します。

## 上級（テンション・アプローチ・コード・スケール）

上級の練習は、maj7・m7・7・m7♭5 の 3rd と 7th（12の音高で96項目）の80%が「定着」すると開きます。学習記録の「上級をすべて表示」で、いつでも開けます（学習記録に開放の状態と定着の数を表示します）。上級の練習には「上級」の印が付きます。

- 指板学習のカタログに、テンションのコード（7♭9・7♯9・7♯11・13・7♭13・m11・maj7♯11・6/9）と、ビバップスケール（ドミナント・メジャー）を追加しました。テンションのコードのシェイプは収録していません。♯11 と ♭5、♭13 と ♯5、♯9 と ♭3 は同じ高さでも別の度数として綴ります。
- ハーモニー「テンション」: G7♭9 の ♭9 は? のように、各コードを特徴づけるテンションを答えます（選択肢・音名入力・指板・演奏）。
- ハーモニー「コード・スケール」: コードとその働き（メジャーキーの ii など）から使うスケールを選びます。G7alt → G オルタード（A♭ メロディックマイナーの第7モード）のように、答えのあとに由来とアヴォイドノートを示します。ほかの流派で使われるスケールは、誤りの選択肢には出しません。
- アヴォイドノート: アイオニアン・ミクソリディアンの11、フリジアン・ロクリアンの♭9、エオリアンの♭13 を、代表的な定義として「文脈に依存するガイド」で示します（誤りにはしません）。ドリアンの13は流派によって扱いが異なるため、学習記録の設定でオンにしたときだけ示します。指板学習のスケールの説明にも表示します。
- 進行「アプローチ」（ステップ式）: 各コードの 3rd（または 7th・ルート）へ、パターン（下からの半音、上からの全音階音、二重の半音（上から・下から）、エンクロージャー2種）で到達します。例：Cmaj7 の 3rd へのエンクロージャーは F → D♯ → E。音の順番と距離で判定します（最初の音はどのオクターブでも可）。
- ライン: 許可する度数に「コードトーン＋テンション（9th・13th）」を追加しました。

## 進行（フレーズ）

「進行」タブの上部で「フレーズ」を選びます。短いモチーフ（2〜5音）を合成音で聴き、課題に沿って進行の上で弾きます（1小節カウントのあと自動で進行。最大64小節）。**点数は付けません。**

- 課題: そのまま反復、移して反復（指定したコードの3rdから、半音単位で同じ形）、調の中で移して反復（音階上の段数で同じ形。C–D–E を D–E–F に移すなど）、リズムを変えて反復、休符を入れる、コール＆レスポンス、自由に発展。前の3つだけは音の並びで一致を確かめ（演奏の中のどこかに、続けて弾いた音として現れればよい。リズムは問わない）、残りは自己評価です。
- モチーフ: ライブラリ（6種。一般的な音型で、曲の引用ではありません）またはランダム。調は進行の調（調のない自作の進行では最初のコード）。
- 制約カード: 「3音だけ」「1本の弦だけ」「休符で始める」「8分音符だけ」「各小節の頭は 3rd」「5〜7フレットだけ」など。課題に付けるか、「制約カードを引く」で単独で使えます。弦は判定できないので自己評価です。測れるものは参考の数値（使った音名の数、最初の音の位置、小節の頭の着地、範囲外の音の数）を示します。
- 演奏の記録: 音声入力で確定した音の高さと時刻（おおよそ ±0.1秒）だけを残し、録音はしません。進行の上に音名と度数で並べて表示し、「自分の演奏を再生」で合成音で聴けます。同じ高さの連打は、音の立ち上がりの検出（試験的）が働かないと1音にまとまります。止めても、それまでの記録は残ります。
- 参考の数値（点数ではありません）: 弾いた音の数、使った音名の種類、休符の割合、コードが変わった直後の着地の度数、モチーフとの輪郭の近さ。
- 自己評価: 「モチーフが聞き取れる形で残っていたか」「休符で間を作れたか」「コードの変わり目を意識できたか」「制約を守れたか」をはい／一部／いいえで答え、メモ（200文字まで）を付けて保存します。保存した演奏は直近20件まで残り、一覧から再生できます。自己評価は記録の集計には入りますが、復習の間隔には使いません。

## 耳・リズム（聴音）

左の「耳・リズム」で、アプリが鳴らす短いフレーズを聴いて、同じ音をギターで弾きます。

- 種類: 単音（主音のあとに1音）、インターバル（2音。1音目は表示）、メロディ（2〜8音）、コードトーンのメロディ（調のダイアトニックコードの構成音だけ）。調はメジャー12・マイナー12から選びます。
- 難しさ: 段階1〜8（音数、跳躍の大きさ、調の外の音）。「自動で調整」では2回続けて正解で1段上、1回の誤りで1段下がります。同じ高さが続く問題は既定では出しません（「同じ音の連続も出題」で出題できます。弾き直しは音の立ち上がりで区別するため試験的です）。
- 判定: 音名だけ（既定）またはオクターブも一致。間違えたときは、その場で1音目からやり直すか、最後まで弾いてから比べるかを選びます。
- 再生: 調の手がかり（主音／I–IV–V–I／なし）を鳴らしてからフレーズを再生します。**再生中と再生後0.3秒は入力を判定しません。** マイクで入力するときはヘッドホンを使ってください。R でもう一度聴く（回数制限も可）、S で答えを見る。答えは音名・度数と指板上の位置で示します。
- 歌う: 答え方を「歌う」「歌ってから弾く」にすると、まず歌って音名で判定し（最も近い半音、0.3秒保った音）、続けてギターで弾きます。歌う声の入力チャンネルをギターと分けられます（ボーカル用マイクを別の入力につなぐ場合）。
- ドローン: 指板学習の「スケール」表示で「ドローンを鳴らす」を押すと、ルート＋5度を鳴らし続けます。モードの響き（ドリアンの ♮6 など）を確かめるのに使います。

## 耳・リズム（リズム）

「耳・リズム」タブの上部で「リズム」を選びます。パターン（4分・8分・8分の裏・裏にアクセント・3連・16分・8分＋16分2つ・シンコペーション・休符を含む8分・チャールストン）を、1小節のカウントのあと、クリックに合わせてタップします。タップは Space・Enter・画面の大きなボタン（キーボードとして認識されるフットスイッチも可）です。

- 設定: テンポ 40〜200 BPM、小節数、クリック（すべての拍／2・4拍／1拍目だけ／なし）、スウィング（8分・16分のパターン。50%＝ストレート〜75%）、変形（1拍ずらす／倍の長さ／半分の長さ）。
- 判定: ±35 ms 以内は「ぴったり」、隣の音と重ならない幅（最大 ±70 ms）以内は「許容」、それより外れたものは「早い」「遅い」、予定にない打点は「余分」、打たなかった音は「抜け」。打点は順番を保って予定の音と1対1で対応させます。結果では各マスにずれ（ms）を表示し、平均のずれ（走る・もたる傾向）とばらつきを数値で示します。
- 遅延の補正: 「遅延を補正する」で90 BPM のクリック16回に合わせてタップすると、ずれの中央値（150 ms 以上離れた打点は除く）を補正値として保存し、以後の判定で差し引きます。150 ms を超える場合は、Bluetooth など遅延の大きい出力を使っていないか案内します。
- ギターで打つ（試験的）: 「打ち方」を「ギター」にすると、音声入力の欄が表示され、ギターの音の立ち上がり（ピッキング）を打点として判定します。音の高さは問わないので、ミュートした弦のカッティングでも構いません。遅延の補正値はタップとは別に保存します（補正はミュートした弦をピッキングして行います）。立ち上がりの検出は実機での調整がまだのため、見落としや余分な打点が出ることがあります。

## 学習記録

演奏練習で正解した問題を、設定とは別のファイル `training-data.json`（同じアプリデータ領域）に保存します。直前の正常な記録もバックアップし、破損時は復旧します。保存は30秒ごと・アプリの終了時にまとめて行います。左側の「記録」タブで今日と直近7日の問題数・正答率・回答時間（演奏は音の検出時間を含む）、記録した項目・定着した項目・今日が復習日の項目の数を確認できます。記録の書き出し・読み込み（置き換え）・消去は、画面内で確認してから実行します。音声は保存しません。許容範囲外の安定した音は誤答としては数えず、正解までの経過として残します。苦手ランキング用に、日付・楽器・出題した弦とフレットごとの集計（出題数・正解数・誤り・時間の合計）を `playPositions` として同じファイルに保存します（最新の400日分・20000件まで）。この項目がない以前の記録ファイルも読み込めます。1.1.0 で保存した記録ファイルは、1.0.0 以前のアプリでは読み込めません。

記録タブは上から次の順に並びます。

- 今日の練習: 復習（5分）→ 弱点（5分）→ 新しい項目（3分）→ 進行・フレーズ（5分）のメニューを、記録から自動で作ります。新しい項目は、まだ到達していない最も低いレベルの、まだ答えていない項目です。対象がない段階は省きます。「今日の練習を始める」で各トレーナーへ順に移り、画面下のバーで経過時間を確認して「次へ」で進みます（時間になっても自動では切り替えません）。最後に記録タブへ戻ります。
- 概要: 今日・直近7日の問題数・正答率・回答時間、連続練習日数、項目数、上級の開放の状態。
- レベル: L1 指板（自然音）、L2 指板＋（全音）、L3 インターバル基礎、L4 ガイドトーン、L5 アルペジオ、L6 進行、L7 上級。各レベルの項目の80%が「定着」すると到達し、到達した日を表示します（L1・L2 は楽器ごと）。L4 の数は上級の開放の数と同じです。
- 弱点: コードトーン（品質 × 度数）、インターバル（音名・指板。インターバル × 方向）、指板（弦 × フレット帯）、聴音（音数 × 種類）、リズム（パターン × テンポ帯）の交差表を、知識・指板・演奏の層ごとに表示します。各セルは記号（◎ ○ △ ×、データ不足は …）・正答率・反応時間の中央値を示し、色だけに頼りません。5回未満のセルは「データ不足」です。最大12行（多いときは弱い順）。セルを選んで「苦手を練習」を押すと、そのトレーナーへ移り、その項目だけを出題します（ハーモニー・指板学習。聴音・リズムはその種類・パターンとテンポに合わせます）。苦手の練習中は画面上部に表示し、出題範囲やモードを保存しません。「苦手の練習を終える」で元の設定に戻ります。
- 入力の状態: 直近の演奏・歌の回答のうち、入力の問題（検出の失敗・音割れ）の割合を示します。2割以上のときは、チューナーの画面で入力レベルと無音のしきい値の見直しを案内します。
- 目標の反応時間（右側）: 選択 2.5秒、音名入力 3秒、指板のクリック 3秒、演奏・歌 4秒（既定）。これより速い正解だけが復習の間隔を伸ばします。変更は今後の回答から適用し、過去の記録は計算し直しません。

スキップ・自己判定・入力の問題は、弱点の計算と復習の間隔に使いません（入力の状態の欄だけで数えます）。

出題の順番: ハーモニーの「苦手を優先」（既定はオン）は、一巡のなかで、復習の時期が来た項目 → 弱点（正答率75%未満か目標より遅い）→ 新しい項目 → 練習中 → 定着した項目の順に並べます。一巡ですべての項目を1回ずつ出し、同じ項目・同じコード・同じ答えの音を続けません。指板学習（位置 → 音名、音名 → 位置）にも同じ設定がありますが、既定はオフで、オフのときは従来どおりのランダムな一巡です。

## 開発

Node.js 22.12以上、Rust MSVC、Microsoft C++ Build Tools、Windows SDK、WebView2が必要です。

```powershell
npm install
npm run desktop:dev
```

`npm run dev` は画面の開発用プレビューだけを起動します。こちらの設定保存はブラウザー内です。デスクトップ版はRustを通してファイルに保存します。

```powershell
npm run desktop:build
```

型検査、画面ビルド、RustのReleaseビルドを実行し、`release/Fret Notes.exe` へコピーします。

```powershell
npm run desktop:install
```

上記のビルドに加えて、Inno Setup 6でインストーラー `release/Fret Notes Setup <版>.exe` を作り、`%LOCALAPPDATA%\Programs\Fret Notes` へ管理者権限なしでインストールします。既存のインストールは上書きされ、起動中のアプリは自動で閉じます。スタートメニューとデスクトップにショートカットを作り、「アプリと機能」からアンインストールできます。インストーラーだけを作る場合は `npm run desktop:installer` を使います。WebView2 Runtimeは同梱していません。

## 検証

```powershell
npm test
npm run typecheck
cargo test --manifest-path src-tauri/Cargo.toml --lib
cargo run --manifest-path src-tauri/Cargo.toml --bin audio-probe
```

`audio-probe` はデバイスの情報取得だけを行い、入力は開始しません。`audio-live-probe` は指定デバイスの短い実入力検証用で、明示的なデバイスIDと1〜30秒の実行時間を指定します。保存するレポートは周波数・レベル等の解析結果だけで、音声ファイルは保存しません。

## ソース構成

- `src/domain/`: 音楽理論、指板、シェイプ、出題状態
- `src/features/`: 指板表示、学習画面、チューナー、演奏練習、設定の入出力、音声入力の共有（`audio/`）
- `src/platform/`: TypeScriptとRustの接続、保存要求の順序制御
- `src-tauri/src/`: Rustのアプリ本体、設定保存、音声入力と音高解析
- `src/ui/`: 共通DOM操作とスタイル
- `dist/`: 新版の画面ビルド結果。編集は `src/` で行います
- `legacy/`: 移行前のWeb版ソースとテスト
