# デスクトップ移行の進捗

更新日: 2026-10-13

## 今回の範囲

第4段階（単音の演奏練習）の実装版0.4.0を作成した。既存の学習・任意チューニング・チューナーを維持し、同じ音声入力サービスで演奏を判定する。判定の再現テストと画面操作を確認した。利用者の希望により、オーディオインターフェースの再接続と実演奏による一連の練習確認は後日に回す。

## 実装済み

- Tauri 2 / Vite / TypeScript / Rust の構成。Release版は画面をexeに内包する。
- 音楽理論、指板、シェイプをTypeScriptの独立モジュールへ移行。
- 出題と回答の進行を、DOMに依存しないPracticeSessionへ分離。
- 指板を独立したFretboard部品へ移行。弦数が同じ間はセルを保持し、音名等だけを更新する。
- ギター・4弦/5弦ベースの既存機能を単一画面へ統合。
- オクターブを含む開放弦のMIDI音高と周波数の計算を追加。
- InstrumentProfileに楽器ID・表示名・明示的な弦番号/ID・開放音・フレット数・選択チューニングを集約。
- 標準、Drop D（ギター/4弦ベース）、Drop A（5弦ベース）、半音下げ。楽器ごとの独自設定を12件まで保存・編集・削除。
- チューニング変更を指板・出題・回答判定・コード/スケール位置に一括反映。課題と回答状態をリセット。
- シェイプは開放弦の絶対音高が標準と一致する場合に表示し、未対応チューニングには案内を表示。
- 楽器別の設定をRustから版番号付きJSONで保存。正常データのバックアップ、破損時の復旧、未対応の新しい版の上書き防止。
- 保存要求の順序制御、終了時の保存待機、保存失敗時のJSON書き出し。
- JSON設定の書き出し/読み込み。旧ローカル版の設定書き出しページ。
- CPALによる入力デバイス/チャンネル選択と開始/停止。固定容量バッファ、解析専用スレッド、Tauri channelで結果を通知する。
- 単音チューナー。クロマチック/選択弦、基準周波数、音名/周波数/セント/入力レベル、無音/不安定/入力過大の状態表示。
- 単音の演奏練習。共通の出題範囲、位置ガイド、音高/オクターブ/安定時間の判定、ミュート待ち、一時停止/再開、結果表示。

## 0.1.1 終了不具合の修正

バツを押してもウィンドウが消えない原因は、`onCloseRequested` 内部で呼ばれる `destroy` に必要な `core:window:allow-destroy` 権限の不足だった。メインウィンドウにこの権限を追加し、保存完了後の `close()` 再呼び出しを廃止。Tauriの通常の終了経路で保存完了後にウィンドウを破棄する。

終了処理のテストでは、実際のTauri JavaScript APIとIPCモックに配布設定の権限を適用した。保存完了まで終了を待つこと、連打で保存を飛ばさないこと、未保存処理がない場合の終了、保存失敗時の書き出し機会と次の閉じる操作による終了を確認。既存テストも含めて12件が成功し、strict型検査も通過した。

Release版0.1.1をビルドし、配布先exeとビルド成果物のSHA-256一致を確認した。実機では起動後にAlt+F4（バツと同じCloseRequested経路）で終了し、対象ウィンドウがなくなることとプロセスの終了を確認した。タイトルバーのバツを直接クリックする操作と保存遅延中の実機操作は未検証であり、後者は回帰テストで検証した。

## 0.3.0 チューナー

音声コールバックは選択チャンネルの変換と固定容量バッファへの投入のみを行い、ロック・ファイル保存・UI通知・音高推定を行わない。別スレッドで低域通過フィルター、間引き、YIN系の推定を行う。画面通知は約15 Hzで、未確認の通常通知を1件に制限する。古いセッションの通知や停止要求が、新しい入力を変更しないよう管理する。入力データが1秒途切れた場合や画面の受信確認が2秒途切れた場合は停止する。画面切り替え・最小化・終了も停止経路へ接続した。

## 0.4.0 単音の演奏練習

「演奏練習」タブを追加した。指板学習で保存した弦・フレット・ナチュラル音の範囲とInstrumentProfileを使い、25〜1500 Hz内の位置から出題する。5/10/20問、許容幅±5/10/20セント、安定時間200/350/500 msを選べる。範囲内の位置を一巡するまでは重複させず、可能な場合は前の問題と異なる高さを選ぶ。

音名とオクターブ、推奨位置を表示する。通常の単一入力では弦・フレットを特定できないため、採点するのは絶対音高だけ。位置はガイドとして明記し、別の位置で同じ高さを弾いた場合も正解にする。

判定はDOMから独立したPerformanceSessionに分離した。入力のセッションID、通知順、単調増加の音声時刻を検証し、表示更新をまとめる前に各通知を渡す。入力の到着時刻や画面タイマーを採点に使わない。安定した音が許容幅内で必要な時間続いたときに1回だけ正解とする。250 ms超の通知間隔、無音、入力過大、不安定な音では候補を解除する。

正解後は最低600 ms表示し、200 ms以上続く無音を確認して次へ進む。長いサステインや不安定なアタックを次の問題へ加点しない。再アタックの推定は今回導入せず、明示的なミュートによる離音を採用した。

一時停止、画面切り替え、入力中断では問題と結果を保持する。新しい入力セッションの時刻へ切り替える際は判定候補を破棄し、再開後も離音を待つ。楽器・チューニング・範囲・A4基準の変更では課題を作り直す。音声入力を二重には開かず、チューナーと同じ開始/停止/終了処理を利用する。

全問完了または終了操作で入力を停止し、正解数、許容範囲外の安定した音の回数、正解した問題の聴き取り時間を表示する。回数は同じ安定した不正解音を通知ごとに数えない。結果と判定条件は画面内だけで保持し、アプリ終了時に消える。保存形式はschemaVersion=3のまま。

- 前回の入力ペア(3+4)によるギターE2解析ログを再生し、正解1回、長い音と不安定なアタックでは次の問題へ進まないことを確認した。音声ファイルは保存していない。これは旧推定器の解析結果の再生であり、新版による実演奏の確認ではない。

## 拡張 P1 和声エンジン（画面の変更なし）

更新日: 2026-10-26。即興トレーニング拡張計画（[docs/training-expansion/](training-expansion/README.md)）の P1。版は0.4.0のまま。

`src/domain/music/harmony.ts` を追加した。DOMに依存しない純粋関数で、後続のトレーナーが使う。`theory.ts` は変更していない。

- 綴り: `isSpelledNote`（`^[A-G](♭{1,2}|♯{1,2})?$`。E♯・B♯・C♭・F♭も有効）、`transpose`（上行は既存の `spell`、下行は文字を逆に数えて綴る）、`samePitchClass`。
- インターバル: `IntervalId`（m2〜M13の21種類）、`intervalDegree`（M3→`3`、A4→`♯4`、d5→`♭5`など）、`intervalSemitones`。
- コード: `chordName`、`chordTones`、`toneByRole`（third/seventh/fifth/ninth等。構成式にない度数は null。sus系にthirdなし、6・トライアド・add9にseventhなし、dim7のseventhは `♭♭7`）。
- `parseChordSymbol`: カタログの19品質のsuffixと別表記（`-7`、`ø`、`°7`、`Δ7`、`M7`、`m7b5`、`mMaj7`、ASCIIの `b`/`#` など）。カタログにない記号（`Cmaj13`等）はエラー。
- `diatonicSevenths`: メジャー、ナチュラルマイナー、ハーモニックマイナー。ルートは主音から綴るため、F♯メジャーのviiはE♯m7♭5、G♭メジャーのIVはC♭maj7。機能はメジャーで I/iii/vi=T、ii/IV=SD、V/vii=D。マイナーは i=T、iiø/iv=SD、ハーモニックマイナーのV7=Dだけを付け、他はnull（流派差のため）。

- 和音: 単音エンジンは最低音か、存在しない低音を返す。楽器の音域外の値は音域の窓で除外できるが、ルートを返す場合は単音と区別できない。和音で判定する機能は作らない方針を維持する。演奏練習の「オクターブ: 指定」では、和音や不要な弦の共鳴による音域外の値が「許容範囲外の安定した音」として数えられる可能性がある。
- 室内ノイズ（約 −67 dB）としきい値（−55 dB）の差は約12 dB で、誤検出はなかった。

    - 層（知識・指板・演奏）と楽器（`fb:`・`ivf:`）で絞り込む。
    - 各セルの値: 採点された回答数（正解＋誤答。スキップ・自己判定・入力の問題は含めない）、正答率、反応時間の中央値、定着の割合。
    - 5回未満は「データ不足」。行は最大12行で、多いときは弱い順に残し、残りの行数を示す（12×7 に収めるため。インターバルは最大21種類あるが、記録のある行だけを表示する）。
  - `levelProgress` / `allLevels`: 項目の集合（スロット）は分母を固定する。どの層で定着しても数える（P14 の開放と同じ）。80%で到達。
    - L1・L2 は楽器の全弦の0〜12F（自然音／全音）。
    - L3 は m3・M3・P5・m7・M7 の上行 × 12の音高（F♯ と G♭ は同じスロット）。
    - L4 は `advancedStatus` をそのまま使う（バーと開放の数が必ず一致する）。
    - L5 はトライアド4種（3転回形）と maj7・m7・7・m7♭5（4転回形）× 12の音高＝336。弦セットと方向はスロットに含めない。
    - L6 は maj7・m7・7・m7♭5 × 進行の段階 3rd・7th・3rd と 7th・コードトーン（`chg:`）＝16。ライブラリの代表的な進行で使われる品質から選んだ。
    - L7 はテンション96、コード・スケール132、アプローチ6種 × 4品質＝252。
    - 到達した日は `preferences.levelsReached` に、初めて到達したときだけ書く（L1・L2 は楽器ごと）。記録タブの描画から呼ぶが、2回目は変更がないので通知は繰り返さない。
  - `weightedDeck`: 一巡のすべての項目を1回ずつ、期限が来た項目 → 弱点（正答率75%未満、または中央値が目標より遅い。弱い順）→ 新しい項目 → 練習中 → 定着した項目の順に並べる。
    - 抜き取りではなく並べ替えにした。これで「一巡で全項目」と「定着した項目は低い頻度」の両方を満たす。短い練習（10・20問）では定着した項目まで届きにくい。
    - 同じ項目・衝突する項目（ハーモニーでは同じコード名・共通の答えの音）は続けない。前の巡の最後とも続けない。8件先まで探して入れ替え、残った衝突は最も近い入る場所へ移す。従来の `toneDeck` と同じく、層の中の順番を変えて最大20通り試し、衝突の最も少ないものを使う（コードトーンの全設定 × 39の種で衝突0を確認）。
  - `todayMenu`: 復習（5分）→ 弱点（5分）→ 新しい項目（3分）→ 進行・フレーズ（5分）。
    - 復習・弱点は、トレーナー・種類・層ごとに最も多い組（最大30項目）を対象にする。
    - 新しい項目は、到達していない最も低いレベルの、まだどの層でも答えていない項目（最大30。L1・L2 は指板の位置、L3 はインターバル、L4 はガイドトーン、L7 はテンション。知識の層で出題）。アルペジオ（L5）と進行（L6）は項目を特定できないため、トレーナーを開くだけにする。すべて答えたことがあるレベルでは、この段階を省く（復習・弱点で扱う）。
    - 楽器を含む項目（`fb:`・`ivf:`・`play:`・`play-any:`・`note:`）は、選んでいる楽器のものだけを対象にする。復習・弱点の組は、項目の種類（指板のインターバルは条件ごと）と層で分ける。
    - 進行・フレーズは、コードトーンか進行を練習したことがある場合だけ。対象がない段階は省く。
  - ほかに `streakDays`（連続練習日数）、`inputHealth`（直近200件の演奏・歌の回答に占める入力の問題の割合。10件以上かつ2割以上で案内）、`targetsOf` / `targetFor`（回答方法ごとの目標の反応時間）。
- 出題への組み込み
  - `ToneDrill` と `PracticeSession` に、一巡の並べ方を渡す省略可能な引数を追加した。省略時は従来の `toneDeck` / `core.shuffled` を同じ乱数で呼ぶ（同じ種で同じデッキになることをテストで確認）。

  - 指板学習（位置 → 音名、音名 → 位置）: 同じ設定を追加したが、**既定はオフ**（既存の挙動を変えない）。設定は学習記録の `preferences.study.weighted` に置く（settings.json は変更しない）。
- 苦手を練習（記録タブのセル → そのトレーナー）
  - ハーモニー: 項目IDから問題を作り直し（設定に依存しない。指板のインターバルは項目の条件ごと）、その項目だけを出題する。表示する数は実際に出題できる問題の数。回答方法は項目の層に合わせる（知識 → 選択（音名入力を使っていれば音名入力）、指板 → クリック、演奏 → 演奏）。練習中は設定を保存せず、「苦手の練習を終える」・設定の変更・タブの切り替えで元の設定に戻る。
  - 指板学習: その位置だけを全弦・全フレットの範囲で出題する（知識 → 位置 → 音名、指板 → 音名 → 位置）。範囲・モードは保存しない。練習中は出題範囲の設定を隠す。保存時はこれらだけを元の値で書き、表記などのほかの変更は保存する。
  - 聴音: 種類と音数・半音階に合うレベルに固定する（自動調整はオフ）。リズム: パターン・帯の中央のテンポ・方法（タップ／演奏）に合わせる。どちらもこれらの値は保存しない。

- 目標の反応時間: 選択・音名入力・指板のクリック・演奏（歌・タップ・自己判定は演奏と同じ）を記録タブで選べる（1.5〜6秒）。

  - 弱点の表の「定着の割合」と弱点の判定は、設定した目標を使う。
  - 概要の定着数・レベル・上級の開放は、P14 と同じ既定の目標のまま。目標を変えたときに上級の開放が知らないうちに変わらないようにするため。
  - 反応時間のない項目（リズム・フレーズ）は、弱点の分析では箱だけで定着を判断する（`isMastered` 自体は変えていない）。
