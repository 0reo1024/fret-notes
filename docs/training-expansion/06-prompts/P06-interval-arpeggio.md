# P6 インターバル・アルペジオ・調と機能（ハーモニー・トレーナーの拡張）

あなたは Fret Notes（Tauri 2 + TypeScript + Rust）の開発を担当します。今回は P5 で作った「ハーモニー」タブに、3つの出題の種類を追加します。

1. インターバル
2. トライアド・7thのアルペジオ（転回形・弦セット）
3. 調と機能の知識問題（ダイアトニック）

## 目的
- 仕様は `docs/training-expansion/03-feature-specs.md` の §3.3（インターバル）と §3.4（アルペジオ）、§3.5 のダイアトニックの部分。
- 任意のルートからインターバルを即座に把握し、指板上の形でも理解する。
- フォームを丸暗記するのではなく、構成音とインターバルの理解からアルペジオを弾けるようにする。
- 調の中のコード（ii、V など）と機能（T/SD/D）を即答できるようにする。

## 変更対象と要件
1. **インターバル**（新規・提案名 `src/domain/training/interval-questions.ts`）
   - 出題: ルート × インターバル（段階1〜4の集合）× 方向（上／下／両方）。
   - 綴りは `transpose` を使う（§3.0.5）。
   - 指板モード
     - ルートの位置（弦・フレット）を指板上に R として示す。
     - 「同じ弦」「隣の弦」「指定した弦セット」「±4フレットの窓」の条件を満たす位置を正解にする。
     - 正解の後、「1弦上・1フレット下」のような位置関係を文で表示する。弦の数え方は、既存の「1弦が最も高い」に従う。
   - 演奏: 音高クラス、または「ルートから上の1オクターブ内の絶対音高」のどちらかで判定する。
   - 項目ID は `iv:<root>:<interval>:<up|down>`。指板モードの場合は `ivf:<楽器>:<interval>:<条件>`。
2. **アルペジオ**（新規・提案名 `src/domain/training/arpeggio.ts`）
   - `resolveArpeggio(profile, chord, order, strings?, fretWindow?)`
     - 弦セットとフレットの窓の中で、各弦に順に次の度数の音を置いた位置の列を返す。複数の解がある場合は、すべて返す。
     - 1弦に1音のトライアド／7th を基本とする。
     - 任意チューニングでも、音高から求めるので動作する。
   - 出題: 品質（maj/m/dim/aug、maj7/m7/7/m7♭5/dim7/m(maj7)）× 転回 × 弦セット × 順番（上行／下行／上下行／開始度数を指定）。
   - 判定
     - クリック: 位置の列を判定する（弦・フレットまで）。
     - 演奏: `SequenceTracker` の順番ありで、絶対音高の列を判定する。弦セット・窓の条件は「その解の絶対音高」で表す。
     - **演奏では弦を判定できないことを、画面に明記する。**
   - 同じ音高が連続する問題（オクターブ違いではなく同じ MIDI）は生成しない。
   - 正解の後は、弾いた位置を度数ラベルで指板に表示し、「R から 3rd へは隣の弦の1フレット下」のような関係を示す。
   - 項目ID は `arp:<quality>:<root>:<inv>:<弦セット>:<順番>`。
3. **調と機能**（新規・提案名 `src/domain/training/key-questions.ts`）
   - 出題の例
     - 「E♭ メジャーの ii は?」（答え: Fm7）
     - 「A マイナー（ナチュラル）の ♭VI は?」（Fmaj7）
     - 「G7 は C メジャーで何の機能?」（D）
     - 「D メジャーの V7/V は?」（E7）
   - 回答: 選択肢（コード名の4択）。
   - マイナー II–V–I の V は**ハーモニックマイナーの V7** にする。ナチュラルマイナーのダイアトニックの表（v は m7）とは区別して出題する。
   - 項目ID は `key:<tonic>:<mode>:<roman>`。

## UI・UX 要件
- サブタブで出題の種類を切り替える。設定は種類ごとに preferences へ保存する。
- アルペジオの進み具合は「● ● ○」のように大きく表示し、何音目を待っているかを分かるようにする。
- 指板モードとアルペジオでは、指板を画面の主役にする（出題カードは小さめにしてよい）。
- 誤答は「3音目: C を期待、D が聞こえた」のように具体的に示す。

## 音声認識との連携要件
- アルペジオの演奏の判定には、P2 の `NoteSegmenter` と `SequenceTracker` を使う。最小の安定時間は 120〜200 ms から選べるようにする。既定は P0 で決めた値。
- 誤りの方針は「最初からやり直す」を既定にし、「その音からやり直す」も選べるようにする。

## 音楽理論の検証事項（テストで確認する）
- インターバル: 12ルート × 全 `IntervalId` × 上下で綴りと音高クラスが正しい。A4 と d5 は別の綴り。B♭ から d5 は F♭（拡張ルートのときだけ出題する）。
- 指板モード: 標準チューニングのギターで、G–B 弦間の長3度が「同じフレット」になる。他の隣り合う弦では「1フレット下」になる。この事実を、正解位置の計算から自動的に導けること。
- アルペジオ: 全品質 × 全転回 × ギターの各弦セットで、`resolveArpeggio` の位置の音高クラスが構成音の順番と一致する。窓の外の解を返さない。解がない場合は空になる。
- 調と機能: 12のメジャー調と12のマイナー調で、ローマ数字とコード名の対応が正しい。セカンダリードミナント（V7/ii、V7/iii、V7/IV、V7/V、V7/vi）のルートとコードが正しい（C メジャーなら A7、B7、C7、D7、E7）。
