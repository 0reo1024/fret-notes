今回の結果

    コードトーン

    弦セットは楽器に合わせて選び、1弦に1音・5フレットの幅（最大4フレット差）に収まる形を出題します。この形で届かないコードは出題しません（ギターの dim7、4度チューニングのベースの m7・7・m7♭5・dim7 など）。演奏では音の高さの並びを判定し、弦は判定しません。

    機能はメジャーで I・iii・vi＝T、ii・IV＝SD、V・vii＝D。マイナーは流派による違いが大きいため、i＝T、iiø・iv＝SD、ハーモニックマイナーの V7＝D だけを出題します。

    7♭9・7♯9・7♯11・13・7♭13・m11・maj7♯11・6/9 の、それぞれを特徴づけるテンションを問います（G7♭9 の ♭9 は?）。♯11 と ♭5、♭13 と ♯5、♯9 と ♭3 は同じ高さでも別の度数として綴ります。

    コードと、その働き（メジャーキーの ii など）から、使うスケールを選びます。同じ Dm7 でも ii ならドリアン、iii ならフリジアンです。ほかの流派で使われるスケールは誤りの選択肢に出しません。答えのあとに、メロディックマイナーの何番目のモードか、アヴォイドノートを示します。

    回答方法

    指板・演奏の範囲（演奏では、この範囲の最低音〜最高音を音域として判定します。弦は判定できません）。

        フレーズ

        最初に1小節カウントし、進行の上で自由に弾きます（最大64小節）。記録するのは、音声入力で確定した音（音高と、受け取った時刻のおおよそ ±0.1秒）だけです。同じ高さの音の連打は、音の立ち上がりの検出（試験的）が働かないと1音にまとまります。弦は判定できないため「1本の弦だけ」などは自己評価です。「5〜7フレットだけ」は、その範囲で出せない高さの音の数を参考として示します。

        コードチェンジ

        各コードで、パターンの音を順に弾いて目標の音に到達します（例：Cmaj7 の 3rd へのエンクロージャーは F → D♯ → E）。最初の音はどのオクターブでもよく、そのあとの音はそこからの距離で判定します。半音の音は目標への導音として綴ります（E へは E♭ ではなく D♯）。全音階音は、進行の調の中のコードなら調の音階、そうでなければコードの種類の代表的なスケールから取ります。間違えた音は数えますが、パターンをやり直せば先へ進めます。

        各コードで1音ずつ弾き、前の音から近い距離でつなぎます。条件を満たす経路はすべて正解です。終わると、あなたのラインの特徴と、同じ最初の音から成り立つ他のラインの例を示します（良し悪しの評価はしません）。伸ばしている音が次のコードでも使えるなら、弾き直さなくても次へ進みます。

        最初に1小節カウントします。各コードの窓はコードの始まりから終わりまでで、音の検出の遅れを補うために終わりから0.3秒の猶予があります。各コードに2拍以上・1秒以上が必要です。マイクで入力している場合は、クリック音が入らないようヘッドホンを使ってください（ライン入力なら問題ありません）。

        回答方法

        演奏では指板の範囲の最低音〜最高音を音域とし、どのオクターブでも正解です（弦は判定しません）。前のコードから伸ばしている音が次のコードでも正解なら、弾き直さなくても正解です（共通音の保持）。
